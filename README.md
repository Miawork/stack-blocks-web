# 叠积木 · 网页版

和微信小游戏是同一套游戏代码，加了一层浏览器适配，可以直接在手机或电脑的浏览器里玩。

## 和微信版的区别

- **没有广告**：网页上没有微信的激励视频，道具只通过"转发给好友"获得。
- **转发**：手机上调起系统的分享面板，电脑上是复制链接。分享出去（或复制成功）就发道具，取消则不发。
- **存档**：存在浏览器本地，换浏览器或清缓存会丢。
- **电脑上**：画面是屏幕中间一块手机比例的区域；空格 / 回车可以开始和放下积木。
- 前三关每天零点（北京时间）换新，和微信版完全一致：同一天两边玩到的是同一关。
- 地狱模式（999 层）也在，进度存在浏览器里。

## 本地运行

需要 Node.js 18 或更高版本，不用安装任何依赖。

```
npm start
```

然后在浏览器打开 http://localhost:3000 。

## 部署到 Railway

这个文件夹本身就是一个可以直接部署的 Node 项目：`npm start` 启动 `server.js`，它读取 Railway 提供的 `PORT` 环境变量并监听 `0.0.0.0`。不需要构建步骤，不需要设置任何环境变量。

### 方式一：通过 GitHub（推荐）

1. 在 GitHub 新建一个仓库，把这个文件夹里的全部内容推上去（**`public/` 目录要一起提交**，游戏就在里面）。
2. 登录 Railway，新建项目，选择从 GitHub 仓库部署，选中刚才的仓库。
3. 等第一次部署完成后，在这个服务的 Settings → Networking 里点 Generate Domain，得到一个 `*.up.railway.app` 的网址。
4. 以后每次往仓库推送，Railway 会自动重新部署。

### 方式二：用 Railway 命令行

在这个文件夹里依次执行（命令以 Railway 官方文档为准）：

```
npm install -g @railway/cli
railway login
railway init
railway up
railway domain
```

## 游戏更新后怎么同步到网页版

游戏本体的代码在小游戏工程（`stack-blocks`）里。把两个文件夹放在同一层，然后在本文件夹执行：

```
npm run build
```

它会重新生成 `public/`。之后提交并推送（或再执行一次 `railway up`）即可。

## 文件

```
server.js        静态文件服务器（不依赖第三方包）
package.json     启动命令
public/          打包好的游戏：网页、脚本、声音、图片（部署的就是它）
build.js         打包脚本：从小游戏工程生成 public/
src/wx-web.js    浏览器适配层：用浏览器的能力实现游戏用到的微信接口
src/web-main.js  网页版入口
src/index.html   网页模板
```
